# 2026-08-16 工作日志

## 用户模块需求分析与规划（superpowers 工作流）

**背景**：为 AI 零代码应用生成平台新增用户模块（注册/登录/当前用户/注销/RBAC 权限/管理员管理），要求通过 SPI 下放实现以便未来更换用户框架（Sa-Token/Keycloak 等）。

**已确认的关键决策**（用户拍板）：
1. 模块形态：单 Maven 模块 `ai-code-agent-user`，内部 `spi/`（契约，零框架依赖）+ `local/`（实现）分包
2. SPI 机制：Spring 条件装配（`@AutoConfiguration` + `@ConditionalOnMissingBean` + `app.user.provider=local` 开关），不用 JDK ServiceLoader（事务/注入问题）
3. 会话方案：自研 Opaque Token + Redis（Security STATELESS + Bearer Header），Redis 键 `ua:session:{token}`（滑续 TTL）、`ua:user-sessions:{userId}`（级联踢人）
4. 接口粒度：两个门面 `UserAuthService`（register/login/logout/resolve）+ `UserAdminService`
5. 权限模型：完整 RBAC 五表（t_user/t_role/t_permission + t_user_role/t_role_permission），权限码粒度
6. 账号体系：用户名+密码（BCrypt strength 10）
7. 管理端：常规管理（分页/详情/启停级联清会话/重置密码/分配角色/角色授权）
8. 交付范围：仅后端；单测 + Testcontainers 集成测试 + apifox-cli 同步接口文档

**关键落地事实（可复用，务必记住）**：
- **Maven 构建**：Git Bash 下 `mvn`/`mvnw` 均因 classworlds classpath 路径未做 Windows 转换而报 `ClassNotFoundException: ...Launcher`。已封装本地包装脚本 `.workbuddy/bin/mvn`（硬编码 `D:\base_envir_soft\graalvm-jdk-25` + `apache-maven-3.9.16`），用它替代 `mvn`。
- **Jackson 3**：Spring Boot 4.1 默认用 Jackson 3（`tools.jackson.*` 包），不是 Jackson 2（`com.fasterxml.*`）。JSON starter 是 `spring-boot-starter-jackson`（不是 `spring-boot-starter-json`）。`ObjectMapper` = `tools.jackson.databind.ObjectMapper`，异常 `tools.jackson.core.JacksonException`（非受检）。
- **Boot 4 测试注解迁移**：`@WebMvcTest`/`@AutoConfigureMockMvc` 移到 `org.springframework.boot.webmvc.test.autoconfigure` 包；web 测试 starter 是 `spring-boot-starter-webmvc-test`。`@MockitoBean`（`org.springframework.test.context.bean.override.mockito`）替代 `@MockBean`。
- **xbatis 1.10.6 API**：实体 `@Table("t_x")` + `@TableId`（默认 IdAutoType.AUTO，联合主键用 `@TableId(IdAutoType.NONE)`）；Mapper 继承 `MybatisMapper<T>`；查询用 `QueryChain.of(mapper).eq/like/in(...).list()/.count()/.get()/.exists()`，OR 条件用 `.andNested(c -> c.like(...).or().like(...))`，分页 `.limit(offset,size)`，删除用 `DeleteChain.of(mapper).eq(...).execute()`。为便于单测，给 Mapper 加默认方法封装查询，服务调用默认方法、单测直接 mock。
- **@Transactional**：local impl 走 auto-config `@Bean` 返回接口类型，Boot 默认 `proxyTargetClass=true`（CGLIB）保证 @Transactional 生效。
- **集成测试**：本地无 Docker，改为本地 PG(5432)+Redis(6379)；测试库 `ai_code_agent_test`（手动创建），`application-test.yml` + `@ActiveProfiles("test")`。IT 命名 `*IT`（surefire 默认不跑，用 `-Dtest=*IT` 手动触发）。
- **apifox-cli**：`endpoint create --file <Windows路径>`（MSYS 路径 `/d/...` 会失败，需 `D:/...`）；JSON 文件中文用 `ensure_ascii=True`（`\uXXXX`）稳妥。

**产出**：`ai-code-agent-user` 模块（spi 契约 + local 实现：PasswordHasher/SessionRepository/LocalUserAuthServiceImpl/LocalUserAdminServiceImpl/自动装配）；Flyway `V2__user_rbac.sql`（五表+预置 admin/admin123）；web 层 SecurityConfig/TokenAuthenticationFilter/401·403 JSON/AuthController/UserAdminController/DTO；ErrorCode 扩展（USERNAME_EXISTS 1001 等）；ArchUnit 守卫（web 不依赖 user.local、spi 零框架）；Apifox 同步 11 接口（清 demo）。
